## Architecture findings

- **Shared rendering core.** `internal/tpl.TemplateRenderer.Render` is the only
  render path; used by `internal/http/core/errorpage.go` and
  `internal/cli/build/command.go`. Confidence: HIGH.
- **Single response funnel.** All error output flows through
  `core.RespondWithErrorPage` (`internal/http/core/errorpage.go`). It hard-sets
  `X-Robots-Tag: noindex`, negotiates `json`/`xml` from `Content-Type` /
  `X-Format` (only those two; default HTML), and copies only `--proxy-headers`
  request headers to the response. Confidence: HIGH.
- **`/{code}.html` returns HTTP 200.** `errorpage` handler passes
  `fasthttp.StatusOK` regardless of `code`. `/` (`index` handler) instead uses
  the real code, overridable by the `X-Code` header (validated `0 < code <= 599`,
  max 3 chars). Confidence: HIGH.
- **Config relative paths.** `config.FromYamlFile` `os.Chdir`s into the config
  file's directory before resolving template `path` entries, then restores.
  Confidence: HIGH.
- **`envsubst` on config.** `config.FromYaml` runs `envsubst.Bytes` before YAML
  parse, so `error-pages.yml` may reference environment variables. Confidence: HIGH.
- **Template output cache.** In-process map keyed by md5(props)+md5(content),
  2s item lifetime, 1s cleanup tick, cleared on `Close()`. Not configurable via
  flags. Confidence: HIGH.
- **Picker modes.** `first` (default), `random` (once), `i-said-random` (every
  request), `random-daily`, `random-hourly`; explicit template name bypasses the
  picker. Confidence: HIGH (`internal/cli/serve/command.go`, `internal/pick`).
- **Docker image bakes static pages.** `Dockerfile` runs
  `error-pages ... build ./html --verbose --index` into `/opt/html` for reuse in
  other images / the gh-pages demo. Confidence: HIGH.

## Schema vs runtime mismatch (NEEDS HUMAN CONFIRMATION)

`schemas/config/1.0.schema.json` documents a page-code pattern
(alphanumeric/underscore/hyphen), while `config.Validate` only rejects empty
codes and codes containing whitespace. The runtime is more permissive than the
published schema. Not necessarily a bug — flag for maintainer awareness when
changing either. Confidence: MEDIUM (noted in existing wiki page 11).
